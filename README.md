# 毛豆深海

热血日漫风的深海钓鱼小游戏。主角是绑着红头巾的毛豆，开着「毛豆丸」驶向修罗深渊。

## 怎么玩

- **网页版**：用手机或电脑浏览器直接打开 [`web/index.html`](web/index.html)。
- **安卓**：安装 [`maodou-deep.apk`](maodou-deep.apk)（调试签名）。

操作：点击抛竿 → 左右拖动引导鱼钩下沉 → 按住收线，把拉力保持在绿色区间。

## 内容

- 4 个深度区域：阳光浅滩、珊瑚乱斗场、暮光海沟、修罗深渊
- 14 种生物，普通 / 稀有 / 史诗 / 传说
- 竿、线、饵三条升级路线，图鉴，本地存档
- Web Audio 合成的音效与打击音，顶栏可静音

## 源码结构

```
web/index.html          # 自包含网页游戏
android/                # 全屏 WebView 安卓工程
maodou-deep.apk         # 调试 APK
```

美术与音效均为代码生成，无外部素材。
